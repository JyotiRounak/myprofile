# Jyoti Agarwal – Portfolio

React + Vite portfolio.

## Run locally
    npm install
    npm run dev        # http://localhost:5173

## Build / deploy
    npm run build      # outputs dist/ (deploy to Vercel, Netlify, GitHub Pages)

## Customise
All content lives in `src/data.js` (email, links, jobs, projects, stack, metrics).
Colours and fonts are CSS variables at the top of `src/index.css`.
